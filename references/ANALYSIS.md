## Shared DNA (all five)

1. **Premise text on screen from frame 1** — never a title card. The thesis is readable
   before the animation matters (top banner or persistent caption).
2. **One metaphor, one location, max 2 characters.** Story is told through a prop
   (ladder, trophy, block stacks, push-up hood guy). No establishing montage.
3. **Payoff = tonal flip in the last 2–3s.** v4 desaturates to gray + red "I Must Win";
   v2 dims then reveals the 1% + "BELIEVE IN YOURSELF."; v3's tower wobbles.
   The emotional drop lands immediately before the message.
4. **Camera recuts are the pacing engine** in the fast ones (v2, v4): the shot "jumps"
   (zoom/push/re-angle) every ~1–2.5s even though it's one scene.
5. **Micro-beats fill the gaps**: gesture flickers, dialogue pop-ups, grain/light
   flicker, tiny reactions. Something changes at least every ~1s somewhere.
6. **Persistent brand mark** every frame (UNSTOPPABLE / DOMINATORS / SIMPLY ANIMATED).
7. **Lengths**: punchy ones are 9–15s. 25s+ only works for the slow story style (v1).

## Implications for The Wheel (was 25s)

- Compress to ~15.5s. Beats: sprint 0–4s → pull-out 4–6.7s → question 5–7.3s →
  stop+look 7.5–9.7s → hop+walk 9.7–13s → punchline holds to 15.5s.
- Hook text starts at ~0.3s, not 1s.
- Punchline lands ON the realization (he stops → text hits → he leaves → text holds).
- Add mood dim (world goes quiet/gray) at the stop; punchline text gets a red-accent
  word (the lie "PROGRESS." in red, hope "Direction is." in amber).
- Persistent "REALITY LOOP" brand mark, low opacity, bottom center, all frames.

## v6_comparison — "Which one are you?" (NEW video type: comparison matrix)

Four stickmen, four pull-up bars, four labels (OVERTHINKING / MOTIVATION / DISCIPLINE / EGO),
all visible in ONE static frame the whole 29.5s. Zero cuts; camera only drifts laterally.
29.5s works here despite rule 8 because every ~1–2s a DIFFERENT character's state changes.

**Structure (frame-verified):**
- f2 (~1s): "Four men. Four bars." (red accent) — premise readable instantly. All four hanging.
- f6 (~3s): Overthinking sits BELOW his bar, question pop-ups ("what if I fail?"). He never even starts.
- f14 (~7s): "Motivation burned out." — drops off the bar, sits defeated. First dropout.
- f26 (~13s): "Discipline kept looking at Ego." — Ego repping hard/fast, Discipline steady.
- f40 (~20s): "Fifteen. His set was done." — Discipline finishes a counted set, steps OFF, checkmark appears. Motivation still seated.
- f50 (~25s): "Ego couldn't." — Ego fails MID-REP (partial pull-up, sweat drops fly off head).
- f57 (~28.5s): "DISCIPLINE KNOWS WHEN TO STOP." + red end-slate mark. Only Discipline standing, ✓ beside him.

**Why it pulls millions of views:**
1. **Self-identification hook** — the viewer picks "their" character in frame 1, then watches
   their own failure/success play out. The question "which one are you?" is implicit the
   whole video and drives comments (people self-report). No explicit CTA needed.
2. **Parallel entities = built-in comparisons.** Instead of one metaphor evolving, it's a
   race/survival matrix: characters drop out one by one → each dropout is a fresh beat.
3. **Red-accent header lines** rotate every ~2–3s and do ALL the narration. No dialogue.
4. **The winner is the quiet one.** Discipline barely moves, finishes, steps off calmly
   with a ✓ — the payoff flip is restraint (anti-climax as climax).
5. **Body language IS the story**: sitting-below-bar (never started), hanging exhausted,
   mid-rep failure freeze, standing + checkmark. Labels make each a persona.
6. **Starfield dust bg, flat white stickmen, boxed labels** — same visual grammar as ours.

**Steal for e02+ (type B, see .agent/TYPES.md):** labeled frames/columns, sequential
dropouts, red-accent rotating headers, one character visibly "wins" by doing LESS,
end line names the winner in CAPS + red mark. Keep camera static + slow drift; cuts stay zero.

**Why it pulls millions of views (the mechanics behind the feeling):**
1. **Live leaderboard rank badges** — numbers swap between lanes as counts change.
   The viewer roots for a rank, not a character. Second-by-second stakes.
2. **Rep counters = the story clock.** Every number on screen is a scoreboard;
   zero narration needed.
3. **Status tags as vocabulary:** NO REST / GAVE UP / INJURED / BURNOUT / RESTING /
   FINISHED. Each dropout is a fresh beat with a name.
4. **Cut-to-spotlight pacing:** each crisis gets a 2–3s solo full-bleed close-up
   (~9 cuts total). Overview → crisis → back to overview = rhythm.
5. **The winner wins by doing less per second but lasting longest** — anti-climax
   as climax, exactly like v6's Discipline.
6. **Brightness hierarchy at the end:** losers dim to near-black, winner stays lit.
7. **ASCII-glyph particles** (# * + ·) for confetti/injury sparks — matches the
   dotted-`#` skyline. The whole world is made of text; feels authored, cohesive.
8. **CTA = self-identification** ("Which one are you?") — same engine as v6. It drives
   comments (people report which one they are). Thesis line holds alone, then CTA.

**Steal for e02 (type B, leaderboard variant — see .agent/TYPES.md):** live rank badges,
rep counters as the clock, status-tag vocabulary, solo spotlight per crisis, ASCII-glyph
particles, dim-the-losers ending, thesis + "which one are you?" hold. NOTE: v7 proves
hard cuts are viable for THIS type — but our RULE 5 (zero cuts) still stands for our
own episodes unless the user changes it.
